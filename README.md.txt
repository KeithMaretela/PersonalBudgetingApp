# Personal Budgeting App

## Overview
A personal finance desktop application for tracking income, expenses, budgets, and financial activity.

## Goals
- Secure local user authentication
- Track income and expenses
- Manage budgets and categories
- View financial summaries and charts
- Export reports to PDF and Excel
- Support light and dark themes
- Integrate external APIs where appropriate

## Technology Stack
- C# and .NET 10
- WPF
- SQL Server Express
- Entity Framework Core
- Material Design in XAML
- CommunityToolkit.Mvvm
- Serilog
- xUnit

## Architecture
- Presentation
- Application
- Domain
- Infrastructure
- Tests
